
Android の背面レンズを **好きな組み合わせで同時録画** するアプリです。レンズごとに別々のMP4ファイルで保存します。
元プロジェクト [RuggeroCadamuroITA/MultiCam](https://github.com/RuggeroCadamuroITA/MultiCam)（MIT）をフォークして改造したものです。

## 改変について

この版は、Anthropic の AI「Claude」の支援を受けて改変しました。

**動作確認の状況**

| 端末 | 確認できたこと |
|---|---|
| LG Wing | 超広角＋広角の同時録画 |
| Xperia 1 II | 広角・望遠の選択。**超広角は、広角・望遠と同時に使えませんでした**（下の「既知の制限」を参照） |

- 上記以外の端末・機能は未確認です。動作の保証はありません。自己責任でお使いください。
- 同じ論理カメラに超広角・広角・望遠がすべて入っている機種では、3本同時に選べる可能性があります（未確認）。

## 元のアプリからの変更点

| | 元 | この版 |
|---|---|---|
| レンズ | 超広角 + 広角 の2本固定 | 検出した背面レンズから **自由に選択**（超広角 / 広角 / 望遠 / 全て） |
| 保存先 | 本体の Movies/MultiCam（録画後にコピー） | **SDカード** または 本体を選択。**録画しながら直接書き込み** |
| 画面 | 縦のみ | **縦・横**どちらにも対応。回転しても、プレビューが正しい向きで映る |
| プレビュー | 引き伸ばし表示 | 録画される映像と同じ縦横比で、正しい向きに表示 |
| 音声 | 先頭のレンズから複製 | 「全ファイル / 1本のみ / なし」から選択 |
| 画質・fps | 既定は最大・30fps | 既定は **1080p・60fps**。画質は、選択中の各レンズごとに設定（fps は全レンズ共通） |
| 録画中の画面 | 消える | 消えない（スリープ防止） |
| 動作方式 | CameraX 同時カメラ → Camera2 | Camera2（物理カメラ指定、別IDのレンズは別カメラとして開く） |
| 診断 | なし | 「診断」ボタンで、端末が公開しているカメラの一覧を表示 |
| 言語 | イタリア語/英語 | 日本語 |

## 使い方

1. 起動して、カメラとマイクの権限を許可します。
2. 「撮影するレンズ」で、撮りたいレンズをタップします（複数選択可。最低1本は選ばれます）。
   - 「超広角＋望遠」「全て」のボタンで、まとめて選べます。
   - 起動直後は、同時に開けないことが多い別カメラ同士の組み合わせを避けるため、広角1本が選ばれています。
3. 「保存先」で、SDカードか本体を選びます。SDカードが挿さっていれば、SDカードが初期値です。
4. 音声・フレームレート・画質を選んで、⏺ を押します。
5. 選んだレンズの数だけ、MP4が別々のファイルで保存されます。

保存例（`Movies/MultiCam/`）:

```
MultiCam_20261020_072400_ultrawide_0_6x.mp4   ← 超広角
MultiCam_20261020_072400_wide_1x.mp4          ← 広角
```

## 保存のしくみ

- 録画は、選んだ保存先（SDカード / 本体）の `Movies/MultiCam` に**直接書き込み**ます。録画後のコピーや変換はないので、長い動画でも、停止後の待ち時間はほぼありません。
- 録画中のファイルは、MediaStore 上で「保留中」として他のアプリから隠され、停止して保存が成功した時点で公開されます。
- 追加の権限は不要です。SDカードが外れていると、録画を開始せずにエラーを表示します。
- 音声は、既定では全ファイルに録音します。端末が複数ファイルへの同時録音を拒否する場合は、「1本のみ」か「なし」にしてください。
- 録画中は画面が消えないようにしています。電源ボタンで画面を消したり、別のアプリに切り替えたりすると、カメラが切断されて録画が終わります（そこまでの分は保存されます）。
- SDカードが FAT32 の場合、1ファイル4GBまでの制限があります。

## レンズの分類

論理マルチカメラの物理カメラと、別IDで公開されている背面カメラを列挙し、35mm換算焦点距離から分類します。
メイン（換算 約20〜40mm で、画素数が最大のもの）を 1x として、0.75倍未満を超広角、1.5倍超を望遠とします。

## 動作要件

- Android **10（API 29）以上**
- 背面カメラが1つ以上あること
- `CAMERA` / `RECORD_AUDIO` 権限

複数レンズの同時録画ができるかは、端末次第です。

- **同じ論理カメラ**に入っているレンズ同士: 多くの機種で可能です。
- **別々のカメラID**で公開されているレンズ同士: 端末が許可した場合のみ可能です。許可されないと、エラーになります。

## 既知の制限

- **Xperia 1 II**: 超広角が別のカメラIDで公開されており、広角・望遠との同時使用が拒否されます（`ERROR_MAX_CAMERAS_IN_USE`）。端末側の制限で、アプリでは回避できません。
- **LG Wing**: ジンバルカメラは、アプリに公開されていないため、使えません。
- 同時に動かせるレンズ数・解像度は端末依存です。「全て」や4Kの組み合わせは、拒否されたり、動作が重くなったりすることがあります。レンズ数を減らすか、画質・fps を下げてください。
- 録画中は、エンコーダの余裕を確保するため、プレビューを停止します。
- マクロ等の補助レンズが物理カメラとして見える端末では、それも選択肢に出ます。
- 4Kの同時録画は負荷が高く、固まることがあります。1080pをおすすめします。

## ビルド

Android Studio（最新版）でこのフォルダを開き、Gradle の同期が終わったら、▶ で実行します。
コマンドで作る場合:

```bash
./gradlew assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk
```
